# Quick Start

Run:

```bash
acli create
```

Choose a project type and project-specific options — including a local environment for WordPress projects (React/Next.js/Laravel are scaffolded by their own official generators and don't need one). The CLI prints exact next steps after scaffolding.

You can also pass partial or full CLI options:

```bash
acli create --name my-app --preset react
acli create --name my-site --preset wordpress --environment docker
```

See [CLI Options](./cli-options.md) for the full reference.
